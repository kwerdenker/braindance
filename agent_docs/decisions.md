2026-08-01 — Q: Does an unowned namespace let `/jobs/../web/main.js` traverse, as the step-8 handoff said? → Decision: no, the claim is false and was measured. `new URL()` removes dot segments including `%2e%2e`, and `isInside` rejects what is left; four escape attempts served nothing. 2026-08-01 — Q: Should the worker have its own render or encode path? → Decision: no. 2026-08-01 — Q: Can a worker be configured with its renderer class? → Decision: no, it reads it from the browser it will render in. A name resolves to whatever the store holds when the worker reaches it, which is the opposite of reproducing an edit; accepting both shapes would fork the one field that decides what is rendered.

2026-08-01 — Q: Atomic artifact publication model? → Decision: write video and sidecar into a per-job temp directory, then rename the directory once. This makes the pair atomic while preserving the existing separate-file shape.
2026-08-01 — Q: How can a directory rename be atomic when re-exporting the same name is ordinary? → Decision: the final directory is unique per export attempt (`<name>.<pid>-<sequence>`), so `rename(temp, final)` always targets a fresh path. The job record's `output` stays the requested base name and `artifactPath` is the video file inside that directory. Re-exports and requeues create new directories rather than replacing old ones; the old directory remains until something cleans it.
2026-08-01 — Q: Remote monitor admission handshake? → Decision: a remote socket starts ungranted and receives no binary frames until it explicitly requests a grant; while a take is active the ordinary initial grant is the recording cap or coarser, and a finer request is refused unless the client sends `acceptMonitorCost: true`. Loopback sockets remain granted at full rate by default.
2026-08-01 — Q: Is parsing the Host header through `new URL('http://' + host)` sound? → Decision: not on its own. The parser consumes userinfo, a path, a query or a fragment and normalises what is left to the trusted authority, so `Host: evil@127.0.0.1:8231` passed. The shape is checked before the parse and the parse must have consumed only the authority. This hole was opened by the fix that closed the scheme hole.
2026-08-01 — Q: Reserve an output that a `done` job still names? → Decision: no, left deliberate. Re-exporting over a file you already have is the ordinary editing case; the cost is that the older record still names a path a later job rewrote, which is recorded rather than designed around.
2026-08-01 — Q: Does a later export to the same name invalidate the previous artifact? → Decision: no. Unique per-attempt directories mean a later export lands in a new path; the older record still names its older path and is not overwritten, so the queue and the disk agree.
2026-08-01 — Q: Should `requeue` refuse every running job? → Decision: no, that was a deadlock and it was mine.
